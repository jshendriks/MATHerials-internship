# MATHerials internship
As part of the masters Science Education and Communication at Utrecht University I was an intern at Hogeschool Utrecht at the lectorate of mathematical and analytical faculties for professionals. During the internship I developed a prototype for MATHerials based on a digital action-based embodied design developed and researched by the Freudenthal Institute at Utrecht University (https://embodieddesign.sites.uu.nl/). 

## Main features
The prototype can be used to explore the connection between the x-coordinate of the sine graph and the unit circle. The idea is that a user manipulates two grips, one along a line and the other on a circle. Feedback on the movement of the user is provided by a light (or something else depending on your needs). The feedback mechanism is hidden inside a box. This mechanism uses a pulley system to translate circular movement into linear movement and an electrical circuit. The electrical circuit contains a hall effect which closes the circuit if it is near a magnet. The pulley system indicates the length which needs to be travelled by the grip in the line using a magnet. The magnet on the pulley system closes the electrical circuit. The closed electrical circuit turns on the LED and indicates that the user has correctly moved the grips on the lid of the prototype.

## Build instructions
This repository has three folders, namely:
- Documents
- Hardware
- Results
### Documents
The folder Documents contains documentation on the prototype such as the literature on embodied cognition, mathematics anxiety and the digital action-based embodied design on which the prototype is based. Moreover, this directory also contains the internship report concerning this prototype.
### Hardware
The folder Hardware contains files which can be used to reconstruct the prototype yourself such as the step files for the 3D printed parts and ai files for laser cutting the box and the lid of the box.
### Results
The folder Results contains pictures of the prototype made during the internship.

## Outcomes
The main outcome of the internship is a prototype for a physical action-based embodied design.
